## Публикация и откат

Сборка переносит CSS без изменений. `public_html/index.php` читает проверенный статический выпуск из `public_html/yard-static/releases/`. Указатель переключается атомарно; предыдущий выпуск сохраняется. Архив публикации не может содержать WordPress, настройки, базу или загруженные фотографии.

FTP не выбран: сервер отклонил AUTH TLS до авторизации. На Timeweb создана техническая учётная запись `yard-deployer`, которой доступна только публикация дизайна. HTTPS-проверка вернула 401 для анонимного запроса и 503 для действительной технической учётной записи при выключенном механизме публикации. Временный пароль проверки отозван.

До запуска нужны секреты `YARD_DEPLOY_USER` и `YARD_DEPLOY_APP_PASSWORD` в окружении GitHub `timeweb-preview`. Включение `TIMEWEB_DEPLOY_ENABLED` и серверной опции `yard_deploy_enabled` выполняется при пробной публикации, после чего нужно проверить переключение и откат. В репозитории секретов нет.

Исходная статическая копия и её настройки сохранены на Timeweb вне публичной папки. При откате на неё достаточно восстановить сохранённый корневой `.htaccess` с `DirectoryIndex index.html index.htm`. В приватном каталоге также сохранены экспорт базы CMS и архив медиатеки. Эти копии обновляются отдельно от выпусков дизайна.
