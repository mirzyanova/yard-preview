# ЯРД — дизайн-прототип

Это **публичный тестовый сайт**, а не окончательная версия архитектурного бюро ЯРД.

## Как увидеть сайт
После включения GitHub Pages в **Settings → Pages** выберите:
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- Save

Адрес после публикации: https://mirzyanova.github.io/yard-preview/

## Что сейчас работает
- Главная: описание бюро и слайдшоу избранных проектов
- Портфолио: разреженная адаптивная мозаика с подписями при наведении
- Страница каждого проекта: заголовок, стадия, год, перелистываемая галерея и описание
- Контакты; мобильная адаптация; свайп галереи
- Тестовая маршрутизация через `#/...`, совместимая с GitHub Pages

## Важно
**Все проекты и фотографии сейчас демонстрационные и не представляют реальные работы ЯРД.** Фотографии для предварительного просмотра загружаются с внешнего сервиса Unsplash; это временная уступка исключительно ради проверки визуального направления. До окончательного запуска они должны быть заменены материалами бюро и размещены на российском сервере. Шрифты также временные.

## Технический план
1. Утвердить внешний вид и поведение страниц на GitHub Pages.
2. Получить настоящие материалы проектов и лицензированные шрифты.
3. Внедрить систему управления контентом (CMS) и проверить добавление проектов без участия разработчика.
4. Разместить публичный сайт, CMS, изображения, шрифты и базу данных в России.
5. Протестировать, настроить резервное копирование, подключить действующий домен abyard.ru.

GitHub — **хранилище исходного кода** и история изменений. GitHub Pages — только временная площадка для просмотра. После переноса готовый сайт не должен загружать для посетителей рабочие ресурсы с GitHub или других иностранных серверов.
